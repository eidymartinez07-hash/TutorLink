# Accesos de demostración

Solo para una base de datos de pruebas con datos ficticios.

| Perfil | Correo | Contraseña de ejemplo |
|---|---|---|
| Tutor | docente@example.com | DemoTutor!2026 |
| Coordinación | coordinador@example.com | DemoCoord!2026 |

Estas cuentas no se crean automáticamente. En un entorno de pruebas, ejecutar `flask --app app create-demo` e introducir las contraseñas de ejemplo cuando se soliciten, o crear las cuentas desde Coordinación. Si ya existen, el comando no las modifica.

No utilizar estas contraseñas públicas en una instalación con datos reales. Para una demostración pública con datos existentes, usar contraseñas privadas y entregarlas al evaluador por separado. Cambiar o desactivar las cuentas al finalizar.
